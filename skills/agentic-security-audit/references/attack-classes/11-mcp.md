# 11 — MCP

Map authenticated server connections, credential audience, consent, tool namespaces, resource URIs and request/result correlation. Inspect name collisions, model-selected aliases, reconnect/discovery changes, stale cached schemas and async responses. Can server A's result satisfy server B's pending call? Can peer metadata change permissions or suppress required approval?

Require the peer/field the attacker controls, routing or trust decision and unauthorized effect or disclosure. Examine actual handler/resource authorization after dispatch. Record client-side gates separately from guarantees of an external server.

Descriptions, annotations and schemas guide use but do not authenticate a server or authorize effects. A missing server implementation cannot establish a vulnerability in it. State exact provider identity/routing facts needed for validation. Do not assume all MCP deployments use the same transport or authentication mode.
