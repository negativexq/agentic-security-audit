# 09 — RAG and untrusted context

Trace ingestion rights, document/section provenance, retrieval ACL/tenant filters, hybrid search, reranking, prompt caches and citation validation. Check each alternate query and cached result. Can a source's policy claim become a tool capability, target argument or approval? Can trusted provenance be fabricated by caller-controlled metadata?

For isolation require writer or selector control and a reachable consumer of another principal's protected content. For authority require retrieval → privileged decision → effect. A synthetic chunk can demonstrate downstream containment without claiming realistic retrieval rank or model behavior.

Citation membership does not prove entailment, recall or permissions. Unsupported answers may be quality defects; classify security only when a meaningful data, authority or action boundary fails. Missing provider-side controls are unknown, not assumed absent.
