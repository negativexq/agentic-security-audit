# 08 — Prompt injection

List attacker-writable documents, messages, issue bodies, web pages, tool/MCP output, memory and metadata consumed in a privileged context. Trace source provenance through prompt assembly, semantic proposal, deterministic admission and sink. Search for role spoofing, forged prior approvals, tool suggestions and attacker-selected destinations.

Require a code-level trust-boundary failure: unauthorized disclosure, scope expansion or action not intentionally requested/approved by the affected principal. Supply attacker write access, victim consumer, failed control and reachable effect. Distinguish an arbitrary mocked proposal from demonstrated attacker-to-model causation.

A prompt-following model, malicious retrieved paragraph or leaked generic system instruction alone is not a finding. A correctly rejected unsafe proposal is containment evidence. Do not require prompt immunity; examine what the system permits when the model is wrong.
