# 04 — Action binding

Compare intentional request or approved object with the operation actually dispatched. Follow target resolution, material reason/amount/destination arguments, normalization, defaults, batches and transformations. Can one principal's valid permission be used for an action that attacker-controlled context substituted? Can a preview summarize one action while a tool executes another?

Prove the original request/approved object, substituted field, transformation and unrequested effect. Grounding is not ownership: an ID present in a message may be quoted, negated or refer to a different operation. Conversely, a product may safely resolve symbolic references using deterministic rules and a clear preview.

Valid generic authorization does not prove exact user intent. Ordinary intended actions under the requester's own permissions are not delegation defects.
